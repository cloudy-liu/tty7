## 逐提交说明

1. `ac6ba053`，`fix(agents): preserve restored sessions before hooks arrive`。
   恢复 pane 后，在 agent hook 到达前，已知会话 ID 可能丢失，再次重启服务时无法继续
   原会话。现在保留恢复的身份，并识别显式 Codex/Claude resume ID，使重启和恢复过程
   继续关联原会话。会话内容仍由 agent 自己存储。来源：cloudy-liu/tty7#24。
2. `de081500`，`fix(agents): clear ended sessions and validate resume selectors`。
   agent 退出或启动恢复失败后，进程探测可能继续显示旧身份；Claude 参数解析还可能把
   提示词误作会话 ID。现在优先采用结束 hook 和 shell 完成状态，清理失效身份，按参数
   个数解析 resume 选择器，并保留引号内的参数。来源：cloudy-liu/tty7#24。
3. `d4a5d5da`，`feat(ui): use transparent agent icons`。
   彩色圆底压缩图形空间，部分图标在不同主题上对比不足。现在移除圆底，图形占比从
   54% 提升到 78%；19 个 agent 的图标使用主题适配颜色，并针对 13 个内置主题的
   侧栏、标签栏和切换器状态验证 4.5:1 对比度。来源：cloudy-liu/tty7#25。
4. `93c3af3e`，`docs(readme): document latest fork changes`。
   中英文 README 未完整反映上述代码。现在说明会话生命周期、图标行为和 fork 默认值，
   并区分当时的已发布版本与源码改动。该提交与原 7cbf2dd7 文件树相同，重新生成 SHA
   仅用于重新运行 PR 检查，不构成第二次功能更新。来源：cloudy-liu/tty7#26。
5. 本发布提交，`chore(release): prepare 26.8.3-c.6`。
   将 workspace 与 Cargo.lock 中四个 tty7 包从 c.5 升到 c.6，保证 tag、程序和安装包
   版本一致；增加本记录并把 README 中的上述功能归入 c.6。第三方依赖保持原锁定值。
