# v26.8.3-c.5

以 `v26.8.3-c.4` 为基线，只加入 Windows pane 内 SSH 到 Linux 后，Vim `:wq`
回显错位的修复。c.4 原有客制功能和依赖版本均保留。

`v26.9.1-c` 已撤下，Release 和 tag 已删除。`main` 直接 reset 到 c.4 后追加
下面两个提交，停止本轮上游同步。c.4 之后原先引入的 42 个提交不在新发布历史中，
其中的 Vim 修复单独移植到本版本。

## 升级与回退安装

- 从 c.4 可以正常更新到 c.5。
- 已安装 `26.9.1-c` 的用户需要从本 Release 下载 c.5，退出 tty7 后手动安装或替换。
  现有更新器按版本号比较，不会自动从 `26.9.1-c` 降级到 `26.8.3-c.5`。

## 逐提交说明

1. [`86e5b85a`](https://github.com/cloudy-liu/tty7/commit/86e5b85af6363ad603428fb6dd987968b3b3dff3)
   `fix(terminal): keep SSH Vim commands on the command line`。
   Windows 本地 pane 中运行 `ssh.exe` 连接 Linux Vim 时，ConPTY 会传递 Vim 合法的
   隐藏光标、移动、写入 `:`、显示光标序列。原有逻辑把光标恢复到隐藏前的位置，
   导致后续 `wq` 出现在文件显示行。删除这段回写后，回显保留在 Vim 命令行。
   相关问题见 [l0ng-ai/tty7#774](https://github.com/l0ng-ai/tty7/issues/774)，
   最初引入见 [l0ng-ai/tty7#362](https://github.com/l0ng-ai/tty7/pull/362)，
   macOS/Linux 已有的禁用处理见 [l0ng-ai/tty7#442](https://github.com/l0ng-ai/tty7/pull/442)。
   原有 ConPTY 光标防闪烁补偿也随之移除。五个跨平台回归测试覆盖真实 Windows SSH
   输出的最小重放、原始 Vim 输出、主屏幕、擦除后的光标位置及显式移动，并验证整帧、
   单字节和七字节分帧。
2. 本发布提交，`chore(release): prepare 26.8.3-c.5`。
   修复后包版本仍为 c.4，因此将 workspace 和 `Cargo.lock` 中四个 tty7 包的版本
   更新为 `26.8.3-c.5`，让 tag、程序、安装包与更新元数据一致。增加本发布记录、
   README 入口和 `26.9.1-c` 用户的手动回退说明。没有升级第三方依赖。
