# v26.8.3-c.9

以 [v26.8.3-c.8](https://github.com/cloudy-liu/tty7/releases/tag/v26.8.3-c.8)
为基线，加入 Herdr 彩色标签头像及分屏焦点规则。比较范围：
[v26.8.3-c.8..v26.8.3-c.9](https://github.com/cloudy-liu/tty7/compare/v26.8.3-c.8...v26.8.3-c.9)。

## 发布范围

本范围共 7 个 Git 提交，其中 2 个 merge 提交，来自 3 条分支线：

- 1 条 c.8 历史集成线：[cloudy-liu/tty7#36](https://github.com/cloudy-liu/tty7/pull/36)
  的 1 个 merge 提交。
- 1 条 Herdr 功能线：[cloudy-liu/tty7#37](https://github.com/cloudy-liu/tty7/pull/37)
  的 4 个实现与测试提交及 1 个 merge 提交，落实
  [cloudy-liu/tty7#38](https://github.com/cloudy-liu/tty7/issues/38)。
- 1 条 c.9 发布准备线：版本和文档的 1 个提交。

c.8 tag 指向 `011c409d`。之后的 `d1e5215c` merge 与该 tag 的文件树完全相同，
只是把已发布的 c.8 历史接入 main，不增加 c.9 行为。本范围没有上游集成提交；
补丁等价的历史同步共 1 个提交，即 `d1e5215c`。c.9 发布 PR 在打 tag 后的合并
不属于本范围。

## 行为变化

- Herdr 占据 tty7 面板时，标签头像使用深色圆形底与紫色羊形象。即使 Herdr 的
  workspace 内运行 Codex 或 Claude Code，外层仍显示 Herdr，悬浮提示仅为
  “Herdr”；所选面板内 Agent 的状态点仍保留。
- 同一 tty7 标签有独立分屏时，头像及状态点跟随当前聚焦的面板。后台标签和后台
  工作区沿用最后聚焦的面板；旧记录没有焦点信息时取首个面板。左侧栏、顶部标签栏
  与工作区切换器遵循同一规则。
- Herdr 可由 shell 命令标记或前台进程识别，包括不报告命令文本的 Windows shell，
  以及 Herdr 启动嵌套 Agent 的进程树。普通 shell 和独立 Agent 面板保留各自头像。

## 逐提交说明

1. [`d1e5215c`](https://github.com/cloudy-liu/tty7/commit/d1e5215c8fbdcb8fe4ef18fcd3f69c1013e0e1c0)，
   `Merge pull request #36`。c.8 tag 已在发布分支，但 main 尚缺该段历史；通过
   cloudy-liu/tty7#36 合入后，文件树仍与 c.8 tag 完全相同。这是补丁等价的历史
   同步，不是新功能。
2. [`5d554658`](https://github.com/cloudy-liu/tty7/commit/5d554658430675ba5f1c5a541f706b69b3d6bca6)，
   `feat(ui): show Herdr logo for foreground sessions`。此前 tty7 不识别 Herdr，
   面板只会显示终端或内部 Agent 头像。该提交增加 OSC 命令标记与前台进程识别，
   将 Herdr 身份经 daemon 消息、重连和 Unix handoff 传至 GUI，并加入初版头像。
   来源：cloudy-liu/tty7#37、cloudy-liu/tty7#38。
3. [`b3f2fbe3`](https://github.com/cloudy-liu/tty7/commit/b3f2fbe39a8f64ca306c3ac1eefbc64d5ba6f2e7)，
   `feat(ui): keep Herdr avatar across nested agents`。初版同一面板同时检测到 Herdr
   和 Agent 时会优先显示 Agent，后台工作区也缺少 Herdr 身份。该提交采用彩色头像，
   让主应用身份优先，持久化每个标签最后聚焦的面板与每个面板的前台应用，并让三处
   导航使用所选面板的头像和状态点；旧记录回退到首个面板。来源：cloudy-liu/tty7#37、
   cloudy-liu/tty7#38。
4. [`5a225929`](https://github.com/cloudy-liu/tty7/commit/5a2259298863c444e0142852529acb336a735f59)，
   `test(core): align daemon protocol assertion with version six`。初版 Herdr 消息将协议
   版本升至 6，而既有测试仍断言 5，导致完整测试失败。此提交更新断言，使测试
   对应实际协议。来源：cloudy-liu/tty7#37。
5. [`cd87bc14`](https://github.com/cloudy-liu/tty7/commit/cd87bc1477d59920f197294e5d2a0621ecd0e532)，
   `test(ui): populate focused pane in Unix tree fixture`。新增焦点字段后，Unix 专属
   测试里的标签初始化缺少该字段，导致 macOS/Linux 测试编译失败。此提交补齐
   fixture，恢复跨平台测试。来源：cloudy-liu/tty7#37。
6. [`f9235162`](https://github.com/cloudy-liu/tty7/commit/f923516276a624659bdfb170c7d741b431c3b73c)，
   `Merge pull request #37`。将 Herdr 功能和测试修正合入 fork 的 main；merge 的
   文件树与 PR head 相同，没有额外行为变更。来源：cloudy-liu/tty7#37。
7. 本发布提交，`chore(release): prepare 26.8.3-c.9`。将 workspace 与 Cargo.lock
   中四个 tty7 包从 c.8 升至 c.9，更新中英文 README 和本发布记录，使 tag、程序
   与安装包版本一致。第三方依赖未升级。
