# tty7 Session Language

Terms for how tty7 presents terminal sessions and the programs running inside them.

## Language

**Tab avatar**:
The single icon that identifies a tab in navigation. In a split tab, it represents the focused pane, or that pane after the tab moves to the background.

**Host application**:
A terminal application that contains its own sessions within a tty7 pane and can launch coding agents inside them. Herdr is a host application.

**Nested agent**:
A coding agent running inside a host application's session. It remains an agent for status and notification purposes while the host application identifies the pane.
